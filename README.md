## 四、模块边界速查

- **客户 360°** 是客户主数据中心 + 聚合视图，属于业务中台能力的前端入口。
- **品牌库管理** 是产品主数据中心，属于业务中台能力的前端入口。
- **审批中心、流程设计器** 同属工作流平台，一个是运行时入口，一个是建模工具。
- **消息中心、工作台** 都依赖通知中心，不是独立的消息系统。
- **日历模块** 不是独立应用，是任务/拜访/工单/活动共用的视图组件。
- **售后工单与工单看板** 已合并为 **工单管理**，看板只是视图形态。
- **代理商管理** 不包含合规、绩效、驾驶舱、系统管理内容。
