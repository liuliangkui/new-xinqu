## 一、设计目标

1. **统一分类语言**：全系统使用一致的标签体系，避免各应用标签混乱
2. **固定 + 自定义**：系统内置固定标签保证业务语义，用户可创建自定义标签灵活扩展
3. **支持多维度筛选**：标签既是标记手段，也是筛选条件
4. **视觉一致性**：同类标签颜色一致，一眼可识别业务含义
5. **权限可控**：不同角色可见、可用的标签不同

## 二、核心概念

### 2.1 标签作用域

| 作用域 | 说明 | 示例 |
|---|---|---|
| **全局标签** | 跨应用通用，所有应用都可使用 | 重点客户、待跟进、紧急 |
| **应用标签** | 只在特定应用内使用 | 日历的「客户拜访」、意向的「招标」 |
| **对象标签** | 绑定到具体业务对象实例 | 某个客户被打上「战略客户」 |

### 2.2 标签类型

| 类型 | 说明 | 管理权限 |
|---|---|---|
| **固定标签** | 系统内置，有固定名称、颜色、含义 | 管理员可配置是否显示，普通用户不可修改 |
| **自定义标签** | 用户或组织自行创建 | 创建者可修改/删除，管理员可管理全部 |

### 2.3 标签与字段的区别

| 维度 | 标签 | 字段 |
|---|---|---|
| 用途 | 分类、标记、筛选 | 结构化存储对象属性 |
| 数量 | 一个对象可打多个标签 | 一个字段一个值 |
| 灵活性 | 可随时增删 | 变更需要调整数据结构 |
| 示例 | 高价值、紧急 | 客户名称、金额、状态 |

## 三、标签数据结构

### 3.1 标签定义（TagDefinition）

```json
{
  "tagId": "tag_001",
  "tagName": "客户拜访",
  "tagColor": "#3370FF",
  "tagIcon": "visit",
  "tagType": "fixed",
  "scope": "application",
  "applicationId": "calendar",
  "category": "日程类型",
  "sortOrder": 1,
  "visible": true,
  "description": "线下拜访客户的日程标记",
  "creator": "system",
  "createTime": "2026-07-29T00:00:00",
  "updateTime": "2026-07-29T00:00:00"
}
```

### 3.2 标签绑定（TagBinding）

```json
{
  "bindingId": "bind_001",
  "tagId": "tag_001",
  "objectType": "SCHEDULE",
  "objectId": "sch_20260729001",
  "creator": "user_001",
  "createTime": "2026-07-29T09:00:00"
}
```

### 3.3 字段说明

| 字段 | 说明 |
|---|---|
| tagId | 标签唯一标识 |
| tagName | 标签名称，2-6 个汉字 |
| tagColor | 标签颜色，16 色板之一 |
| tagIcon | 标签图标，可选，SVG 图标名 |
| tagType | fixed / custom |
| scope | global / application |
| applicationId | 应用标签所属应用 ID |
| category | 标签分类，如"日程类型"、"业务类型" |
| sortOrder | 排序权重 |
| visible | 是否可见 |

## 七、标签管理

### 7.1 固定标签管理

- 只允许系统管理员或超级管理员修改
- 修改内容包括：显示名称、是否可见、排序、描述
- 不可修改：tagId、tagColor、tagType、scope

### 7.2 自定义标签管理

- 普通用户可创建自定义标签
- 创建时限制：
  - 名称 2-6 个汉字
  - 必须从 16 色板选择颜色
  - 可选择是否带图标
  - 默认作用域为当前应用
- 用户只能修改/删除自己创建的标签
- 管理员可管理组织内所有自定义标签

### 7.3 标签权限

| 操作 | 普通用户 | 部门管理员 | 系统管理员 |
|---|---|---|---|
| 查看固定标签 | ✅ | ✅ | ✅ |
| 使用固定标签 | ✅ | ✅ | ✅ |
| 创建自定义标签 | ✅（应用内） | ✅ | ✅ |
| 修改固定标签 | ❌ | ❌ | ✅ |
| 删除他人自定义标签 | ❌ | ✅（本部门） | ✅ |
| 配置全局标签 | ❌ | ❌ | ✅ |

## 八、标签使用规范

### 8.1 标签展示

- 一个对象最多显示 3 个标签，超出折叠为「+N」
- 标签 hover 显示完整名称和描述
- 标签按固定标签优先、自定义标签其次排序
- 同一分类标签相邻展示

### 8.2 标签筛选

- 列表页支持按标签筛选
- 支持多选标签（AND / OR 逻辑）
- 筛选后显示当前标签条件，支持一键清除

### 8.3 标签输入

- 支持下拉选择已有标签
- 支持输入创建新标签（自定义标签）
- 输入时提示相似标签，避免重复创建
- 固定标签在输入框中置顶展示

### 8.4 标签与颜色一致性

- 同一标签在不同页面颜色必须一致
- 标签颜色与状态色语义保持一致
- 禁止同一标签在不同场景使用不同颜色

## 九、标签组件规范

### 9.1 标签样式

```html
<span class="tag" style="background-color: var(--tag-blue-bg); color: var(--tag-blue-text);">
  客户拜访
</span>
```

```css
.tag {
  display: inline-flex;
  align-items: center;
  gap: 4px;
  padding: 2px 10px;
  border-radius: 999px;
  font-size: 0.786rem; /* 11px */
  font-weight: 500;
  line-height: 1.4;
  white-space: nowrap;
}
```

### 9.2 带图标的标签

```html
<span class="tag tag-blue">
  <svg class="tag-icon" aria-hidden="true"><!-- icon path --></svg>
  <span>客户拜访</span>
</span>
```

### 9.3 标签组

```html
<div class="tag-group">
  <span class="tag tag-blue">招标</span>
  <span class="tag tag-red">高价值</span>
  <span class="tag tag-orange">紧急</span>
  <span class="tag-more">+2</span>
</div>
```

---

## 十、禁止事项

- 禁止使用 emoji 作为标签图标（统一用 SVG）
- 禁止标签名称超过 6 个汉字
- 禁止一个对象绑定超过 5 个标签
- 禁止固定标签颜色被用户修改
- 禁止相同含义标签重复创建
- 禁止标签颜色与状态语义冲突
