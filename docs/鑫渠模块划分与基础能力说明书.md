# 鑫渠模块划分与基础能力说明书

> **文档版本**：v1.0  
> **更新日期**：2026-07-29  
> **对应原型**：《鑫渠高保真原型.html》v1.8.0  
> **文档定位**：明确鑫渠 CRM 的应用层、业务中台层、基础平台层边界，消除模块重叠，统一共用能力下沉为基础服务。

---

## 一、设计原则

1. **一层只干一层的事**：应用层面向角色完成业务闭环；中台层沉淀跨应用复用的业务能力；基础平台层提供通用技术与通用业务能力。
2. **共用能力必须下沉**：被 2 个及以上应用使用的功能，不得重复在各应用文档中独立设计，必须抽象为基础服务。
3. **视图不等于应用**：列表、看板、日历、地图只是同一业务对象的不同展示形态，不应拆成独立应用。
4. **配置能力不等于应用**：流程设计器、字段设计器、权限配置器等是支撑应用的配置工具，不是业务应用本身。

---

## 二、三层架构总览

```
┌─────────────────────────────────────────────────────────────┐
│                         应用层                               │
│  面向特定角色、有独立业务闭环、能产生直接业务价值的入口        │
├─────────────────────────────────────────────────────────────┤
│  线索管理 │ 意向管理 │ 设备管理 │ 试剂运营 │ 工单管理        │
│  经销商协同 │ 合规风控 │ 目标绩效 │ 经营驾驶舱              │
├─────────────────────────────────────────────────────────────┤
│                       业务中台层                             │
│  跨应用共享的业务能力中心，提供统一领域服务与主数据            │
├─────────────────────────────────────────────────────────────┤
│  客户中心 │ 产品中心（品牌库）│ 订单中心 │ 经销商中心       │
│  营销中心 │ 合规中心 │ 绩效中心                               │
├─────────────────────────────────────────────────────────────┤
│                       基础平台层                             │
│  通用技术能力与通用业务能力，所有上层模块共享                  │
├─────────────────────────────────────────────────────────────┤
│  组织权限平台 │ 工作流平台 │ 通知中心 │ 搜索服务 │ 标签服务  │
│  文件服务 │ 日志审计 │ 应用配置平台 │ 日历视图组件          │
└─────────────────────────────────────────────────────────────┘
```

## 三、应用层（Application Layer）

应用层面向终端角色，提供完整的业务操作入口。每个应用必须有明确的服务角色、核心对象和业务价值。

### 3.1 业务管理域

| 应用 | 服务角色 | 核心对象 | 业务价值 |
|---|---|---|---|
| **线索管理** | 销售代表、销售经理 | 线索 | 低门槛商机登记与分配 |
| **意向管理** | 销售代表、销售经理、区域总监 | 意向单 | 高门槛项目报备与审批 |
| **设备管理** | 销售代表、FAE、售后工程师 | 设备档案 | 设备全生命周期管理 |
| **试剂运营** | 销售代表、商务运营、经销商 | 试剂档案 | 消耗预测、复购预警、上量分析 |
| **工单管理** | 售后工程师、服务主管、客户 | 售后工单 | 服务请求处理与 SLA 监控 |
| **品牌库管理** | 产品运营、系统管理员 | 品牌/型号/注册证 | 产品主数据统一维护 |

> **重要说明**：售后工单与工单看板合并为 **工单管理**；看板只是工单的视图形态之一。

### 3.2 渠道协同域

| 应用 | 服务角色 | 核心对象 | 业务价值 |
|---|---|---|---|
| **经销商协同** | 渠道管理员、经销商老板/销售 | 经销商档案、授权、返利、库存 | 厂家与经销商在线协同 |

> **边界约束**：经销商协同只包含经销商档案、授权区域/产品线、区域保护、返利结算、库存共享/调拨、经销商门户。不包含拜访合规、学术活动、样品管理、飞检、敏感词审计（这些属于合规域）。

### 3.3 合规审计域

| 应用 | 服务角色 | 核心对象 | 业务价值 |
|---|---|---|---|
| **合规风控** | 合规专员、销售代表、市场专员 | 拜访记录、学术活动、样品、飞检任务 | 销售/市场/服务全过程合规 |

### 3.4 数据决策域

| 应用 | 服务角色 | 核心对象 | 业务价值 |
|---|---|---|---|
| **目标绩效** | 销售总监、区域总监、销售经理 | 绩效目标/达成 | 多级目标拆解与达成跟踪 |
| **经营驾驶舱** | 高管、区域负责人、运营分析员 | 指标/预警 | 全局指标监控与下钻分析 |

### 3.5 平台级入口

平台级入口不是业务应用，而是聚合不同应用待办/数据/快捷操作的统一入口。

| 入口 | 定位 | 依赖基础能力 |
|---|---|---|
| **工作台** | 每日工作总入口 | 通知中心、任务中心、日历视图 |
| **消息中心** | 消息与待办统一入口 | 通知中心 |
| **应用中心** | 应用导航与收藏 | 应用配置平台 |
| **通讯录** | 联系人统一入口 | 组织权限平台、客户中心 |
| **任务** | 个人/团队任务管理 | 任务中心、日历视图、通知中心 |
| **收藏夹** | 用户个人快捷入口 | 用户偏好服务 |

> **重要说明**：「日历」不是独立应用，而是被任务、拜访、工单、学术活动共用的**视图组件**。

## 四、业务中台层（Business Middle Platform）

业务中台沉淀跨应用共享的业务能力与主数据，以领域服务的形式对外提供接口。

| 中台 | 负责领域 | 对外提供的能力 | 消费方 |
|---|---|---|---|
| **客户中心** | 客户域 | HCO 主数据、科室、决策链、客户健康度 | 线索、意向、设备、试剂、工单、合规、驾驶舱 |
| **产品中心（品牌库）** | 产品域 | 品牌、厂家、产品线、型号、规格、注册证 | 意向、设备、试剂、工单备件、经销商授权 |
| **订单中心** | 订单域 | 订单/合同、回款、送货、发票 | 意向、绩效、驾驶舱、经销商返利 |
| **经销商中心** | 经销商域 | 经销商档案、授权、区域保护、返利规则 | 经销商协同、意向、库存 |
| **营销中心** | 营销域 | 拜访任务、学术活动、样品、市场活动 | 合规风控、任务、日历 |
| **合规中心** | 合规域 | 合规规则、敏感词、飞检、审计日志 | 合规风控、经销商协同（调用校验） |
| **绩效中心** | 绩效域 | 目标拆解、达成计算、同比环比、预警 | 目标绩效、经营驾驶舱 |

---

## 五、基础平台层（Foundation Platform）

基础平台提供通用技术与通用业务能力，所有上层模块共享，禁止在应用文档中重复设计。

### 5.1 组织权限平台

| 能力 | 说明 |
|---|---|
| 用户管理 | 账号生命周期、部门/岗位绑定 |
| 角色权限 | 功能权限、数据权限、字段权限、操作权限 |
| 数据范围 | 本人/本部门/本区域/全部/自定义 |
| 脱敏规则 | 按角色对敏感字段脱敏 |

> **相关文档**：《后台设置功能与交互说明.md》中「组织用户」「权限中心」属于组织权限平台的前端配置入口。

### 5.2 工作流平台

| 能力 | 说明 |
|---|---|
| 流程建模 | 可视化流程设计、节点配置、条件分支 |
| 流程运行时 | 流程实例推进、待办生成、审批日志 |
| 流程监控 | 异常实例、超时预警、人工干预 |

> **相关文档**：
> - 《流程设计器功能与交互说明.md》是工作流平台的**建模工具**。
> - 《审批中心功能与交互说明.md》是工作流平台的**运行时待办入口**。
> - 两者不是独立应用，而是同一平台的不同视图。

### 5.3 通知中心

| 能力 | 说明 |
|---|---|
| 消息模板 | 站内信/企微/短信/邮件模板管理 |
| 待办生成 | 审批待办、任务待办、预警待办 |
| 推送渠道 | 站内消息、企业微信、短信、邮件 |
| 已读/未读 | 消息状态管理 |

> **相关文档**：《消息中心功能与交互说明.md》《工作台功能与交互说明.md》都是通知中心的**消费端视图**。

### 5.4 搜索服务

| 能力 | 说明 |
|---|---|
| 全局搜索 | ⌘K 跨应用搜索 |
| 应用内搜索 | 按模块搜索、拼音/首字母/模糊查询 |
| 权限过滤 | 按用户数据范围过滤搜索结果 |

> **相关文档**：《搜索引擎设计规范.md》是搜索服务的规范说明。

### 5.5 标签服务

| 能力 | 说明 |
|---|---|
| 标签定义 | 全局标签、应用标签、对象标签 |
| 标签绑定 | 业务对象打标、解绑、查询 |
| 色板与权限 | 标准色板、标签可见范围 |

> **相关文档**：《鑫渠标签体系设计规范.md》是标签服务的规范说明。

### 5.6 应用配置平台

| 能力 | 说明 |
|---|---|
| 字段设计器 | 按应用定义字段、类型、校验、权限 |
| 视图设计器 | 列表/详情/卡片视图配置 |
| 流程绑定 | 为应用启用工作流平台中的流程 |
| 权限矩阵 | 应用内角色权限配置 |
| 数据字典 | 枚举值、级联字典管理 |
| 版本与发布 | 配置版本、灰度发布、回滚 |

> **相关文档**：
> - 《应用配置功能与交互说明.md》是应用配置平台的总说明。
> - 《后台设置功能与交互说明.md》中的「数据字典」「系统参数」属于应用配置平台的一部分。
> - 《流程设计器功能与交互说明.md》中的应用绑定属于应用配置平台与工作流平台的交界。

### 5.7 日历视图组件

| 能力 | 说明 |
|---|---|
| 时间轴展示 | 日/周/月视图 |
| 事件聚合 | 任务、拜访、工单、活动统一展示 |
| 拖拽调整 | 调整时间、创建事件 |

> **定位**：日历是**视图组件**，不是独立应用。被任务、拜访、工单、学术活动等模块调用。

### 5.8 其他基础能力

| 能力 | 说明 |
|---|---|
| 文件服务 | 附件、图片、PDF 上传/预览/下载 |
| 日志审计 | 操作日志、登录日志、配置变更日志 |
| 数据导入导出 | Excel/CSV 模板导入、批量导出 |
| 地理位置服务 | 定位、距离计算、地图展示 |

## 七、禁止事项

1. **禁止把视图当应用**：看板、日历、地图只是视图，不得独立成应用文档。
2. **禁止把配置工具当应用**：流程设计器、字段设计器、权限配置器是基础平台的前端工具。
3. **禁止跨域重复设计**：拜访合规、学术活动、样品、飞检、敏感词只属于合规域，不得写在经销商协同中。
4. **禁止在应用文档中重复定义基础能力**：搜索、标签、权限、通知、工作流只需在基础平台文档中定义一次，应用文档引用即可。
