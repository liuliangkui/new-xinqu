## 一、模块定位与目标

### 1.1 模块定位

目标绩效是鑫渠 CRM 销售结果管控域的核心模块，支持多维度目标拆解、达成跟踪与未达标预警。

### 1.2 解决的核心问题

- 目标制定与下发缺乏系统承载，往往停留在 Excel 或口头，无法与 CRM 业务数据联动。
- 销售过程中无法实时掌握目标完成进度，月底才发现缺口，丧失补救窗口。
- 多维度绩效数据分散在意向、订单、回款、拜访等模块，人工汇总效率低、口径不统一。
- 经销商协同绩效（授权区域达成、返利达标率、库存周转、任务协同完成率）缺少统一视图。
- 未达标原因分析依赖线下会议，缺少系统化的下钻与归因能力。

### 1.3 带来的业务价值

| 价值点 | 说明 |
|---|---|
| 目标可视化 | 从公司级到个人级的目标树形结构一目了然，责任到人。 |
| 过程可追踪 | 将目标与意向、订单、回款、拜访等业务事件关联，自动计算达成率。 |
| 风险早预警 | 低于时间进度、低于历史同期、连续未达成等场景触发系统预警。 |
| 决策有依据 | 为经营驾驶舱提供核心指标来源，支持高管实时查看全局健康度。 |
| 激励可量化 | 为销售提成、经销商返利、绩效评级提供客观数据依据。 |

## 二、业务场景与角色

### 2.1 使用角色

| 角色 | 关注点 | 典型操作 |
|---|---|---|
| 销售代表 | 本人月度/季度销售目标、达成进度、未达标预警 | 查看个人绩效看板、录入补缺口计划 |
| 销售经理 | 团队目标拆解、成员达成排名、过程指标 | 下发子目标、审批目标调整、查看团队排名 |
| 区域总监 | 大区业绩达成、区域对比、资源调配 | 查看区域绩效地图、分析未达标区域 |
| 销售总监 | 全公司目标达成、同比环比、趋势预测 | 查看经营驾驶舱、导出绩效分析报告 |
| 渠道管理员 | 经销商授权达成、返利达标率、库存共享协同 | 配置经销商绩效指标、监控渠道目标 |
| 经销商负责人 | 本公司任务完成、返利进度、与厂家协同 | 查看经销商门户绩效页、提交达成说明 |
| 财务对账员 | 回款目标、返利结算依据、审计留痕 | 核对回款达成数据、导出对账报表 |
| 系统管理员 | 目标模板、绩效周期、指标字典、数据权限 | 维护绩效周期与指标、配置计算规则 |

### 2.2 典型业务场景（四要素格式）

| 场景编号 | 角色 | 触发条件 | 操作流程 | 预期结果 |
|---|---|---|---|---|
| PJ-01 | 销售总监 | 年初制定全年销售目标 | 导入/录入公司级年度目标 -> 按区域/产品线/人员逐级拆解 -> 发布并锁定 | 形成完整目标树，各层级目标自动汇总 |
| PJ-02 | 销售代表 | 每日查看个人绩效 | 进入目标绩效 -> 切换「我的绩效」页签 -> 查看本月目标、达成率、缺口 | 实时了解个人业绩与健康度 |
| PJ-03 | 销售经理 | 月中发现团队达成落后 | 进入团队绩效 -> 按人员下钻 -> 查看未达标成员 -> 发起辅导或调整资源 | 及时干预，缩小业绩缺口 |
| PJ-04 | 区域总监 | 季度复盘会议前 | 进入区域绩效 -> 切换同比/环比视图 -> 导出区域对比报告 | 获得结构化复盘数据 |
| PJ-05 | 渠道管理员 | 经销商季度返利结算前 | 进入渠道绩效 -> 查看授权区域达成、库存周转、任务协同完成率 -> 生成绩效凭证 | 为返利结算提供客观依据 |
| PJ-06 | 销售总监 | 经营驾驶舱查看全局指标 | 进入驾驶舱 -> 查看目标达成核心卡片 -> 点击下钻到目标绩效详情 | 高管快速掌握全局达成情况 |
| PJ-07 | 系统管理员 | 新绩效周期开始 | 创建新周期 -> 配置指标字典 -> 设置目标模板 -> 启用数据回算 | 新周期目标体系可用 |
| PJ-08 | 经销商负责人 | 月末核对本公司任务 | 登录经销商门户 -> 查看渠道绩效页 -> 核对授权区域销售额/装机量 | 了解返利进度与待完成任务 |

## 三、核心功能清单

| 序号 | 功能名称 | 优先级 | 功能说明 | 原型对应 |
|---|---|---|---|---|
| 1 | 绩效周期管理 | 必要 | 支持按年、季、月定义绩效周期，配置起止时间、数据锁定日与归档策略。 | 周期管理页 |
| 2 | 目标模板配置 | 必要 | 按组织层级/业务类型预置目标模板，支持销售额、回款额、装机量、拜访量、新客数等指标组合。 | 模板配置页 |
| 3 | 目标拆解与下发 | 必要 | 公司级目标按区域、产品线、部门、人员逐级拆分，支持公式分摊、手动调整与审批锁定。 | 目标拆解页 |
| 4 | 达成数据自动回算 | 必要 | 对接意向、订单、回款、拜访、设备装机等模块，按指标口径自动汇总实际完成值。 | 数据回算任务页 |
| 5 | 多维度绩效看板 | 必要 | 提供个人、团队、区域、产品、渠道等多维视图，支持列表/卡片/图表切换。 | 绩效看板页 |
| 6 | 同比环比分析 | 重要 | 支持本期与上期、同期对比，展示增长率、趋势曲线与归因提示。 | 趋势分析页 |
| 7 | 未达标预警 | 重要 | 当达成率低于时间进度、历史同期或预设阈值时，触发系统消息、邮件、企业微信通知。 | 预警中心页 |
| 8 | 多维度下钻分析 | 重要 | 从公司级汇总逐层下钻到区域、人员、客户、产品线，定位未达标根因。 | 下钻分析页 |
| 9 | 绩效排名与排行榜 | 重要 | 按达成率、增长额、完成值等维度生成排名，支持个人/团队/区域榜单。 | 排行榜页 |
| 10 | 经销商渠道绩效 | 必要 | 单独展示经销商授权区域达成、返利达标率、库存周转、任务协同完成率等指标。 | 渠道绩效页 |
| 11 | 绩效调整与变更审批 | 重要 | 支持目标值调整申请，记录变更原因、审批流程与版本留痕。 | 调整审批页 |
| 12 | 绩效报告导出 | 重要 | 支持 PDF/Excel 导出个人、团队、区域绩效报告，含图表、明细与备注。 | 报告导出弹窗 |
| 13 | AI 问答入口预留 | 可选 | 在绩效看板与驾驶舱预留 AI 问答入口，支持自然语言查询目标达成情况。 | 看板右上角 |
| 14 | 经营驾驶舱指标对接 | 必要 | 为目标达成率、同比环比、未达标预警等核心指标提供接口，供驾驶舱实时刷新。 | 驾驶舱数据接口 |

## 四、业务流程

### 4.1 流程一：绩效目标制定与拆解

```
[创建绩效周期] -> [配置目标模板] -> [录入公司级目标] -> [逐级拆解] -> [审批锁定] -> [目标生效]
```

| 步骤 | 操作内容 | 负责角色 | 异常分支 |
|---|---|---|---|
| 1 | 系统管理员在「绩效周期管理」中创建新周期（如 2026 Q3），设置起止时间与锁定日。 | 系统管理员 | 若周期重叠，系统提示冲突并阻止创建。 |
| 2 | 配置目标模板，选择指标集合（销售额、回款额、装机量、拜访量等）与默认权重。 | 系统管理员 | 若缺少必要指标，系统提示补充。 |
| 3 | 销售总监录入公司级目标总值，可按区域、产品线预设拆分比例。 | 销售总监 | 若目标值为空或为负数，表单校验失败。 |
| 4 | 系统自动按拆分比例预生成下级目标，区域总监/销售经理可手动调整。 | 区域总监/销售经理 | 若下级汇总与公司级目标不一致，系统高亮差异并要求确认。 |
| 5 | 提交目标拆解结果，进入审批流程；上级审批通过后目标锁定。 | 销售总监 | 若审批驳回，退回调整并保留版本记录。 |
| 6 | 目标锁定后，系统自动开启数据回算，实时更新达成进度。 | 系统 | 若回算任务失败，发送告警给管理员并支持手动重跑。 |

### 4.2 流程二：日常达成跟踪与预警

```
[数据回算] -> [生成达成看板] -> [触发预警规则] -> [推送通知] -> [用户查看并处理] -> [记录处理结果]
```

| 步骤 | 操作内容 | 负责角色 | 异常分支 |
|---|---|---|---|
| 1 | 系统每日定时从订单、回款、拜访、装机等业务表回算实际完成值。 | 系统 | 若源数据缺失或口径异常，记录异常日志并跳过该指标。 |
| 2 | 按人员/区域/产品/渠道维度生成达成看板，展示目标值、完成值、达成率、缺口。 | 系统 | 若某维度未配置目标，显示「未设置目标」占位。 |
| 3 | 系统运行预警规则，识别达成率低于时间进度、低于同期、低于阈值等场景。 | 系统 | 若预警规则配置为空，默认不触发。 |
| 4 | 对命中规则的目标对象推送系统消息、邮件或企业微信通知。 | 系统 | 若用户未绑定通知渠道，仅保留站内消息。 |
| 5 | 用户进入「我的绩效」或「团队绩效」查看预警详情，可填写补缺口计划或申请调整目标。 | 销售代表/经理 | 若用户无权限查看该维度，系统返回 403 并记录审计日志。 |
| 6 | 处理结果回填系统，形成闭环记录。 | 用户 | 若超时未处理，升级预警等级并通知上级。 |

### 4.3 流程三：经销商渠道绩效结算

```
[配置渠道指标] -> [经销商任务下发] -> [协同数据回算] -> [生成渠道绩效] -> [返利达标判定] -> [输出结算凭证]
```

| 步骤 | 操作内容 | 负责角色 | 异常分支 |
|---|---|---|---|
| 1 | 渠道管理员在「渠道绩效」中配置经销商授权区域、销售指标、返利规则与库存周转要求。 | 渠道管理员 | 若授权区域重叠，系统提示区域保护冲突。 |
| 2 | 将任务下发至对应经销商账号，经销商负责人在门户中确认接收。 | 经销商负责人 | 若经销商未确认，任务仍生效但标记「待确认」。 |
| 3 | 系统自动回算授权区域内订单、回款、装机、库存共享、任务协同完成数据。 | 系统 | 若授权区域边界数据归属存在争议，标记待人工复核。 |
| 4 | 生成渠道绩效看板，展示销售额达成率、返利达标率、库存周转天数、任务协同完成率。 | 系统 | 若库存数据未接入，库存周转指标显示「数据缺失」。 |
| 5 | 根据返利规则判定是否达标，生成达标/未达标结论与返利金额预估值。 | 系统 | 若返利规则存在多版本，按生效日期取最新版本。 |
| 6 | 财务对账员核对后输出结算凭证，支持导出 Excel/PDF。 | 财务对账员 | 若核对不通过，退回渠道管理员重新确认。 |

### 4.4 绩效目标状态机

| 当前状态 | 触发条件 | 下一状态 | 操作人 |
|---|---|---|---|
| 草稿 | 发布目标 | 已发布 | 目标创建人/上级 |
| 已发布 | 审批通过 | 已锁定 | 审批人 |
| 已发布 | 审批驳回或撤回 | 草稿 | 审批人/创建人 |
| 已锁定 | 发起目标调整申请并审批通过 | 已调整 | 目标责任人/上级 |
| 已调整 | 重新提交并审批锁定 | 已锁定 | 审批人 |
| 已调整 | 撤销调整 | 草稿 | 创建人/系统管理员 |

> 注：周期归档后，已锁定目标自动转为只读历史态，不再允许调整，状态枚举值保持「已锁定」。

### 4.5 预警处理状态机

| 当前状态 | 触发条件 | 下一状态 | 操作人 |
|---|---|---|---|
| 待处理 | 责任人开始处理 | 处理中 | 责任人/上级 |
| 处理中 | 填写处理说明并提交 | 已处理 | 责任人 |
| 待处理/处理中 | 确认无需处理 | 已忽略 | 责任人/上级 |
| 已处理 | 复核不通过 | 处理中 | 上级/管理员 |
| 已忽略 | 重新激活 | 待处理 | 上级/管理员 |
| 待处理 | 超时未处理并触发升级 | 待处理（等级提升） | 系统 |

## 五、页面结构与布局

### 5.1 入口

- PC：应用中心 -> 目标绩效
- 小程序：工作台 -> 应用中心 -> 目标绩效
- 快捷入口：经营驾驶舱「目标达成率」卡片点击下钻、个人工作台 KPI 卡片

### 5.2 页面清单

| 页面名称 | 页面类型 | 说明 |
|---|---|---|
| 绩效看板 | 列表/看板页 | 个人、团队、区域、产品、渠道等多维绩效总览。 |
| 目标拆解页 | 树形编辑页 | 公司级目标逐级拆分、调整、审批。 |
| 绩效详情页 | 详情页 | 单个对象（人员/区域/产品/渠道）的详细绩效数据与趋势。 |
| 目标调整申请 | 抽屉/弹窗 | 发起目标值调整，填写原因并提交审批。 |
| 预警中心 | 列表页 | 汇总全部未达标预警与处理状态。 |
| 排行榜 | 列表页 | 个人/团队/区域排名展示。 |
| 渠道绩效页 | 列表/详情页 | 经销商授权区域达成、返利、库存、协同任务绩效。 |
| 周期管理 | 列表页 | 绩效周期、状态、锁定策略管理。 |
| 指标字典 | 列表页 | 绩效指标定义、口径、数据来源配置。 |
| 报告导出 | 弹窗/任务页 | 选择维度与格式，生成并下载绩效报告。 |

## 七、交互设计要点

### 7.1 搜索筛选

| 交互项 | 规则 |
|---|---|
| 周期筛选 | 默认选中「当前周期」，支持切换历史周期与全部周期。 |
| 指标筛选 | 支持单选，按指标类型分组展示。 |
| 区域/人员筛选 | 支持级联选择，选择区域后人员下拉仅显示该区域人员。 |
| 关键词搜索 | 支持按目标对象名称模糊搜索，回车触发。 |
| 筛选记忆 | 用户切换 Tab 或刷新页面后保留最近筛选条件（会话级）。 |
| 筛选重置 | 提供「重置」按钮，一键恢复默认筛选。 |

### 7.2 视图切换

| 视图 | 展示形式 | 默认条数 | 适用场景 |
|---|---|---|---|
| 列表视图 | 多字段表格 | 12 条 | 数据量大，快速扫描 |
| 卡片视图 | 4 列网格 | 8 条 | 数据量小，概览呈现 |
| 图表视图 | 趋势图+环形图+排名 | -- | 分析汇报场景 |

- 切换视图、切换 Tab、执行筛选后自动重置到第 1 页。
- 图表视图支持点击数据点下钻到明细。

### 7.3 操作反馈

| 操作 | 反馈方式 |
|---|---|
| 保存目标拆解 | Toast 提示「保存成功」，差异未消除时弹窗确认 |
| 提交审批 | Toast 提示「已提交审批」，审批待办进入消息中心 |
| 调整目标 | 弹窗填写原因，提交后显示「调整申请已提交」 |
| 导出报告 | 显示生成进度，完成后提供下载链接 |
| 数据回算失败 | 红色提示条，显示失败原因与「重新回算」按钮 |
| 权限不足 | 页面显示「暂无权限查看此数据」，并记录审计日志 |

### 7.4 空态

| 空态场景 | 展示内容 |
|---|---|
| 无绩效周期 | 提示「暂无绩效周期，请联系管理员创建」，提供「查看帮助」链接。 |
| 当前周期无目标 | 提示「当前周期尚未设置目标」，提供「去拆解目标」按钮。 |
| 筛选无结果 | 提示「未找到匹配数据」，提供「重置筛选」按钮。 |
| 无达成数据 | 提示「暂无业务数据，目标达成率按 0% 计算」。 |
| 无预警记录 | 提示「当前没有未达标预警」。 |
| 无权限 | 提示「暂无权限查看」，引导联系管理员。 |

### 7.5 快捷操作

| 位置 | 快捷操作 |
|---|---|
| 看板全局指标卡片 | 点击指标数字下钻到对应明细页 |
| 列表行 | 悬停显示「详情」「下钻」「申请调整」快捷按钮 |
| 详情页头部 | 提供「导出报告」「申请调整」「发送提醒」快捷入口 |
| 预警中心 | 支持一键「标记已处理」「填写补缺口计划」「通知上级」 |
| 驾驶舱入口 | 目标达成率卡片点击直接进入目标绩效看板 |

### 7.6 异常处理

| 异常场景 | 处理规则 |
|---|---|
| 目标拆解上下级不一致 | 底部显示差异条，提交审批前强制确认差异原因。 |
| 数据回算源模块异常 | 跳过异常指标，记录日志，发送管理员告警，其它指标正常展示。 |
| 多用户同时编辑目标 | 采用乐观锁，保存时检测版本号，冲突时提示「目标已被他人修改，请刷新后重试」。 |
| 目标被锁定后编辑 | 仅允许通过「目标调整申请」流程修改，直接编辑按钮置灰。 |
| 跨数据范围查看 | 系统按权限过滤，越权访问记录审计日志。 |
| 绩效周期重叠 | 创建/编辑时校验，重叠则阻止并提示冲突周期。 |

### 7.7 表格排序与分页规则

| 规则项 | 说明 |
|---|---|
| 默认排序 | 绩效看板按「达成率 升序」排列，未达标项优先；排行榜按「达成率 降序」排列；预警中心按「触发时间 降序」排列。 |
| 排序切换 | 列表表头支持点击切换升/降序，单次仅支持单一字段排序。 |
| 分页可选条数 | 列表视图支持 12 / 24 / 48 / 96 条每页；卡片视图支持 8 / 16 / 32 条每页。 |
| 默认条数 | 列表视图默认 12 条，卡片视图默认 8 条。 |
| 分页记忆 | 用户切换页码或条数后，同一会话内保持选择。 |
| 跨页操作 | 批量操作仅作用于当前页，全选需二次确认。 |

## 九、核心设计原则与要点

| 原则 | 说明 |
|---|---|
| 目标与业务联动 | 绩效目标必须与 CRM 业务数据（订单、回款、拜访、装机）自动关联，避免手工统计。 |
| 层级清晰、责任到人 | 目标树必须支持公司->区域->部门->人员/产品线/经销商的多级拆解。 |
| 实时回算、及时反馈 | 关键指标按日回算，达成看板尽量接近实时，预警即时触达。 |
| 多维度可下钻 | 从汇总到明细支持逐层下钻，未达标原因可追溯。 |
| 权限严格、数据安全 | 不同角色仅能看到权限范围内的目标与达成数据，敏感字段脱敏。 |
| 异常可处理 | 数据回算异常、目标拆解差异、权限越权等场景必须有明确的处理路径与日志。 |
| 预留扩展性 | 指标字典、目标模板、周期类型支持灵活配置，为后续 AI 问答、经营驾驶舱预留接口。 |
| 移动端可用 | 销售代表核心查看场景必须支持移动端，关键图表与列表适配小屏。 |

## 十一、未考虑到的问题补充

1. **指标口径冲突**：同一指标在不同业务模块可能存在多种统计口径（如销售额是否含税、是否扣除退货），需在指标字典中明确定义并支持版本管理，避免各部门各执一词。
2. **跨周期目标调整**：当销售总监在周期进行中调整公司级目标时，下级已锁定目标如何联动更新，是否需要强制解锁或走调整审批，需补充规则。
3. **数据回算性能**：大规模组织在回算日/周/月指标时可能产生大量计算，需评估批处理性能、增量回算策略与缓存机制，避免影响业务高峰。
4. **经销商数据归属争议**：同一医院可能位于多个经销商授权区域交界，或存在跨区域合作，需明确归属判定规则与争议仲裁流程。
5. **目标值为零或极小值的场景**：当目标值很小或为零时，达成率计算可能出现极大值或除零异常，需在公式中设置兜底逻辑与异常标记。
6. **多币种与汇率处理**：若存在海外业务或多币种订单，绩效目标的币种统一、汇率更新时机、历史汇率追溯需提前设计。
7. **离职/调岗人员目标继承**：人员发生组织架构变动时，其历史目标与完成值如何归属到新负责人或部门，需设计转移与归档规则。
8. **AI 问答的数据权限**：预留 AI 问答入口时，必须确保 AI 只能返回当前用户权限范围内的数据，避免越权泄露敏感信息。
9. **移动端图表适配**：复杂趋势图、树形拆解在移动端展示可能信息过载，需设计简化视图或关键指标优先策略。
10. **与外部 ERP/财务系统对接**：若回款、库存数据来自外部系统，需设计接口同步机制、失败重试、对账与差异处理流程。
11. **目标调整的审计留痕**：每次目标值变更不仅要记录新值，还要保留旧值、变更人、变更原因、审批记录，满足合规审计要求。
12. **返利计算的精确性与法律依据**：渠道绩效中的返利金额涉及财务结算，需与法务/财务确认计算精度、开票规则与合同条款一致性。
